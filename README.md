# Save you in history

## Идея компании

**Save you in history** — точка моментальной печати туристического фото в историческом центре города. Клиент фотографируется рядом с достопримечательностью, система стилизует снимок под историческую газету или старую городскую открытку и печатает его на месте. Внизу открытки или на обороте размещается реклама локальных ресторанов, отелей и сервисов с QR-кодом или купоном.

Модель выручки: B2C-продажа фото туристу + B2B-реклама локальных партнеров + дальнейшее масштабирование через франшизу.

## Состав группы

Айрапетян Эрик — анализ целевой аудитории, маркетинговая кампания, география компании, итоговая аналитика по запуску.

## Что исследуется

Проект проверяет, где и для кого запускать первую точку, насколько подходит Санкт-Петербург как стартовый город, какие партнеры могут покупать рекламное место на фото и при каких параметрах точка выходит в положительную юнит-экономику.

Ключевые вопросы:

1. Кто является целевой аудиторией B2C и B2B?
2. Почему первый запуск логичен в Санкт-Петербурге?
3. В каких зонах исторического центра стоит начинать пилот?
4. Какие источники данных подтверждают спрос и партнерскую базу?
5. Какая экономика одной точки при разных сценариях продаж?

## Источники данных

Используются разные типы открытых источников. Один из них собирается статическим парсингом, что закрывает требование проекта.

| Источник | Тип | Для чего используется |
|---|---:|---|
| Официальный сайт Администрации Санкт-Петербурга | статическая страница | турпоток 2025, вклад туризма в экономику |
| Турбарометр / Visit Petersburg, итоги 2024 | PDF / открытая аналитика | цели поездок, NPS, семейные туристы, структура расходов |
| Visit Petersburg: «Места» | статический парсинг | список достопримечательностей и адресов для зон запуска |
| 2GIS: рестораны, гостиницы, рубрики «Поесть» | статический парсинг | оценка B2B-базы для рекламы и купонов |
| UNESCO World Heritage Centre | справочная страница | историческое позиционирование продукта |

Полный реестр источников: `data/raw/source_registry.csv`.

## Использованные темы курса

В проекте специально оставлены технические элементы, которые показывают применение тем курса:

- **статический парсинг** через `requests` и `BeautifulSoup`;
- **pandas** для обработки таблиц;
- **matplotlib** для графиков;
- **ООП**: базовый класс коллектора, dataclass-модели источников и юнит-экономики;
- **Dash**: файл `src/save_history/dashboard.py` для интерактивного дашборда;
- **Selenium**: опциональный динамический парсер `src/save_history/selenium_dynamic_parser.py` для JS-страниц.

## Быстрый запуск

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
python -m save_history.main --collect
```

По умолчанию `--collect` использует локальные HTML-снимки, чтобы проект воспроизводился без интернета. Для обновления данных из сети:

```bash
python -m save_history.main --collect --online
```

Дашборд:

```bash
python -m save_history.dashboard
```

Тесты:

```bash
pytest -q
```

## Главные выводы

1. **Стартовый город — Санкт-Петербург.** В 2025 году город принял 12,4 млн туристических поездок; туристический вклад в экономику достиг 843,1 млрд рублей. Это достаточная база для пилота в историческом центре.
2. **Основная B2C-аудитория — культурно-познавательные туристы, семьи и туристы 18–44.** В 2024 году культурно-познавательные цели дали 51,4% поездок туристов из регионов России, а семейные туристы составили более половины внутреннего потока.
3. **B2B-аудитория — рестораны, кофейни, отели и локальные сервисы рядом с туристическими точками.** По 2GIS в городе есть тысячи потенциальных партнеров в категориях еды и размещения.
4. **Первая зона запуска — Невский проспект — Казанский собор — Дом книги.** Эта зона получает лучший итоговый балл за счет сочетания трафика, партнерской плотности и операционной простоты.
5. **Экономика пилота чувствительна к дневному числу печатей.** В базовом сценарии точка безубыточна примерно от 23 отпечатков в день при 5 рекламных партнерах и цене 590 рублей.
